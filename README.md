# Provat Somadder — Personal Portfolio

A responsive, static personal portfolio website designed for free deployment with GitHub Pages.

## Files
- `index.html` — page content
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/profile.jpg` — add your portrait here (see below)

## Add your photo
1. Choose a clear, professional portrait.
2. Rename it to `profile.jpg`.
3. Put it inside the `assets` folder, replacing the placeholder instructions.
4. Keep the filename exactly `profile.jpg`.

Until you add a photo, the site displays a simple PS placeholder.

## Personalize before publishing
In `index.html`, replace:
- `YOUR_EMAIL@example.com` with your public contact email.
- The LinkedIn and GitHub homepage links with your profile URLs.
- Any academic status or project wording that has changed.

Review all personal details before making the site public.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account: https://github.com/
2. Create a new **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload all files and folders from this project (not the ZIP file itself).
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. Wait a few minutes. Your site should appear at:
   `https://YOUR-GITHUB-USERNAME.github.io/`

GitHub Pages supports static websites. This project does not require a paid domain, hosting plan, database, or build step.

## Important
This is a public website. Do not publish private phone numbers, home address, identity documents, passwords, or other sensitive information. GitHub Pages is for static content; a contact email link opens the visitor's email app and does not provide a private message database.
